# トーインコントローラー

マリンジェット（水上オートバイ）のトーイングアクティビティ用予約管理システムです。スマートフォンやタブレットの画面に最適化されており、ネイティブアプリのような操作感でご利用いただけます。

## 主な機能
- **4列独立スクロール**: 船体ごとの独立した縦列で予約を管理。各列は個別にスクロール可能です。
- **ドラッグ＆ドロップ機能**: 予約カードの長押し＆ドラッグ、または列ヘッダーのドラッグによる列の並べ替えに対応。
- **直感的なスワイプ操作**: 予約時間や人数の入力欄を上下にスワイプして数値を簡単に増減できます（時間は5分刻み）。
- **メニュー別の色分け**: D（黄色）、M（赤色）、U（青色）、J（黒色）、X（紫色）のメニューカラー表示。
- **PWA（プログレッシブ・ウェブ・アプリ）対応**: スマホのホーム画面に追加して全画面（スタンドアロン）で起動可能。
- **設定の保存**: マリンジェット名、スタッフ名、既定の待ち時間はローカルストレージに自動保存されます。

## 導入・公開手順（GitHub Pagesの利用方法）

1. 本リポジトリ（または新規リポジトリ）に以下の5つのファイルを同じ階層（ルートディレクトリ）にアップロードします：
   - `index.html`
   - `manifest.json`
   - `sw.js`
   - `icon.svg`
   - `README.md`
2. GitHubの **Settings > Pages** から、Branchを `main` (または `master`) に設定して保存します。
3. 数分後、発行されたURLにスマートフォン（Safari / Chrome）でアクセスします。
4. ブラウザのメニューから **「ホーム画面に追加」** を選択すると、ホーム画面にアプリのアイコンが追加され、全画面で起動できるようになります。
